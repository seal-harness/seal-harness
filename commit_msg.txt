Include session display title in watch notifications

The notification now shows both the tab number and the session display
title (the same label the web frontend sidebar shows). The title is
fetched from GET /api/sessions and resolves via the same cascade as
the frontend's sessionDisplayTitle: description, autoSummary,
firstMessageSnippet, agent name, short id.

Notification format changed from:
  Tab 7 finished thinking
to:
  Tab 7 (Add /watch command for chat channels) finished thinking

Added httpGetSessions to HttpClient and sessionDisplayTitle/sessionJsonId
helpers to Loop.
