## 5. Key Decisions & Rationale

Each of these was argued over several rounds; do not re-open without new evidence.

- **`mode` is deleted, replaced by `allow_localhost :: Bool` (default `true`).** Rev 3c
  kept `mode` and moved to `allow_local`; the simplification is that `allow_localhost`
  answers exactly one question and `WhereLocal` is reachable only when it is `true`. The
  default stays `true` because that is today's behaviour (confirmed by the operator).
- **No localhost denylist.** Rev 7 enumerated loopback spellings, numeric re-encodings,
  `127.0.0.0/8`, `localAddressNames`, `nodeName`/FQDN plus a deferred host-key layer.
  **All deleted.** The operator's call: trust the passkey-authenticated user. An address
  denylist cannot bind the principal who owns the file. The real control is that **no
  agent-reachable path can add a machine**.
- **`execution.toml` lives in `~/.seal/config/`, not `~/.seal/` top level.** Rev 4's
  argument for the top level was backwards — `spConfig = home </> "config"` (`Paths.hs:88`),
  so `config/` *is* under `~/.seal/`. The right distinction is purpose: `security.toml` is
  a *decision* (never git-versioned, per design V8); `execution.toml` is *provisioning
  data* like `repos.toml`, and git-versioning it is the point.
- **The write route mirrors `POST /api/repos`.** Passkey-gated by the existing
  default-deny `accessControlMiddleware`, serialised by a dedicated lock, `.tmp` + rename.
  **Not** `writeSecretFile` — it opens `trunc = True` and writes in place, so a partial
  write leaves a truncated inventory.
- **`access_mode = "none"` must not permit machine mutation.** `decide` short-circuits
  `AccessOpen -> AuthAllow` for every path (`AccessControl.hs:305`), so the predicate must
  be **method + path** (`POST`/`DELETE` on `api/machines`) — a bare path match would 403
  `GET /api/machines` on every `none` install.
- **WU-9's guarantee is deliberately weak.** The `-f remote-only-untrusted` coercion is
  verified at the function level only; the *artifact* property (that `Local` is absent from
  the binary) belongs to issue **#347**. Confirmed by the operator.
- **WU-10 (`group` sanitisation) is excluded.** Pre-existing bug; cannot reach
  `execution.toml`; own PR. The operator's `MEMORY_WRITE` ruling applies by the same
  reasoning.
- **`erMeta.machine` is deferred.** It would measure *use* rather than *configuration*,
  which is the better instrument, but costs a third `UIOEnv` field across 92 sites and is
  not the deciding metric.
